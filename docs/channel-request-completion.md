# Ручное завершение заявки на канал

Этот сценарий выполняет один оператор после того, как сервисный бот добавлен
администратором в канал и webhook получил хотя бы один `channel_post`.

1. В служебной странице заявок найдите номер заявки.
2. По логу webhook или локальной БД получите числовой `telegram_chat_id` уже
   обнаруженного канала. Не используйте username вместо chat id.
3. Выберите уникальный slug: только строчные латинские буквы, цифры и дефисы.
4. Из корня репозитория запустите:

```powershell
npm.cmd run channel:complete -- --request-id 123 --telegram-chat-id -1001234567890 --slug my-channel
```

Скрипт в одной транзакции проверяет заявку и обнаруженный канал, создаёт сайт,
помечает заявку как `done` и привязывает к ней сайт. Если сайт для канала или
привязка к заявке уже существуют, изменений не будет. Успешный результат —
`Done: /site/my-channel`.

Сначала примените миграции:

```powershell
npm.cmd run db:migrate
```
