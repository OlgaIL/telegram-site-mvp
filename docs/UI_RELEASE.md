## До изменения production

1. Метрика: выбрать/найти счётчик, получить номер; подключить и локально проверить код. Сейчас в исходниках и публичном HTML счётчик не найден. Отдельно согласовать настройки аналитики и тексты уведомления; не переносить настройки Word2you автоматически.
2. Яндекс: Ольга выполняет настоящий вход. Проверить адрес callback в приложении провайдера, успешный вход, выход и возврат в /add-channel. Наличие кнопки не означает, что всё работает. При необходимости сначала исправить конфигурацию и перепроверить.
3. VK: проверить приложение VK ID, callback, state/PKCE и настоящий вход. На production кнопка отсутствует. Не включать до успешной проверки; если проверка не завершена, явно согласовать релиз с выключенным VK.
4. L-01/L-02: завершить применимые тексты, контакт для обращений и подтверждение права на канал. Окна с информацией не закрывают эти пункты.
5. Подтвердить финальный коммит, успешные тесты и сборку; затем отправить ветку codex/email-auth в origin (до публикации на сервер).
