# Яндекс Метрика

Счётчик: 113788018 (предоставлен Ольгой 25.10.2026).

- Подключается один раз в корневом layout после гидратации.
- Инициализация defer:true; просмотры отправляются вручную при изменении pathname, без дублей при повторных эффектах.
- Работает только в production-сборке на tg4you.ru и www.tg4you.ru. На localhost/dev/других preview-доменах скрипт не загружается.
- Вебвизор, карта кликов, ссылки и точный показатель отказов включены согласно предоставленному коду. Ecommerce не подключён: оплаты в MVP отсутствуют.
- Почта и OTP помечены ym-disable-keys; формы входа, аккаунт, кабинет, заявки и админка — ym-hide-content.
- Вручную отправляемые URL/referrer не содержат query/hash; персональные параметры и userID не передаются. Не считать это глобальной фильтрацией всех данных стороннего скрипта.
- Уведомление cookie версии v2 описывает Метрику и Вебвизор; политика/соглашение остаются отдельной незакрытой задачей.
- Noscript-пиксель намеренно не вставлен, чтобы исключить localhost-визиты в сборке без выполнения JS-проверки хоста.

Проверка: npm test (включает scripts/metrika.test.js), npm run build --prefix client; на localhost подтвердить отсутствие удалённого скрипта и наличие маскировки. Реальное получение визита/Вебвизор подтвердить с Ольгой после публикации. A-02 до этого не закрывать.
